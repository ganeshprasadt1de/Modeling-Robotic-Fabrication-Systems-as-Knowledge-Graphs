# Modeling Robotic Fabrication Systems as Knowledge Graphs

This repository contains a simplified robotic timber fabrication system modeled as a knowledge graph.

The system includes three KUKA KR6 R900 robots, robot tools, sensors, controllers, workstations, and a timber slab with a column.

The main graph file is `wood_slab_robot_graph.ttl`.

The SPARQL query is `query_lift_capacity.sparql`.
